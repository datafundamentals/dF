This content is only visible after Google authentication.

Protected Features:

  • View your personalized dashboard
  • Access premium content
  • Manage your account settings
  • Connect with other users

Your user ID and auth token are available in:

  • localStorage.getItem('User') - Full user object
  • sessionStorage.getItem('Authorization') - Bearer token
  • document.cookie - Auth token cookie

Accessing User Info in JavaScript:

// Get the auth wrapper element
const authWrapper = document.querySelector('df-auth-wrapper');

// Listen for user changes
authWrapper.addEventListener('df-auth-wrapper-user-changed', (e) => {
  const user = e.detail.newValue;
  if (user) {
    console.log('User signed in:', user.displayName, user.email);
    console.log('User ID:', user.uid);
  } else {
    console.log('User signed out');
  }
});

// Access user from localStorage
const userJson = localStorage.getItem('User');
if (userJson) {
  const user = JSON.parse(userJson);
  console.log('User UID:', user.uid);
}

// Access auth token
const authHeader = sessionStorage.getItem('Authorization');
console.log('Auth header:', authHeader); // "Bearer "
