# Dev Sequence for DF Apps - 'splainer

Deploying an app seems like such a simple thing. Run the script! You're done. If only.

TL;DR: To make things easy, we add 6 smaller steps, which, of course, creates difficulty. 

This document attempts to explain:

- **Motives** for MPA design, and high level parts.
- **What Could Possibly Go Wrong?** Where things get AFU.
- **Breakdown** of 7 steps added to make the process workable.
- **Coding** Actual code for each step.

MPA is a slightly more challenging aspect of the SPA pattern.

## What Could Possibly Go Wrong?
